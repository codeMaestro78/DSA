# Mock interview authoring template

Phase 6 supplies [nine complete sessions](../13-Mock-Interviews/README.md). This form is for authoring a new variation; an unfilled template is not a completed mock. Keep candidate tasks and interviewer guidance in separate files, and preserve the common [rubric v1.0](../13-Mock-Interviews/Interview_Evaluation_Rubric.md).

## Candidate file

- Mock ID / target role / level / editorial difficulty / company-neutral [INFERRED] scope:
- Total duration minutes, excluding preflight and debrief:
- Prerequisites, tools and independent/coached/assisted mode:
- Exactly stated contract, supplied facts and dataset; identify intended clarification points:
- Timeline with positive stage minutes summing to the total:
- Ordered task IDs and requested artifacts; no expected answer, algorithm reveal or hidden solution in this file:
- Link to a separate interviewer file, clearly marked as a spoiler:
- Source scope and actual validation status:

## Interviewer companion file

Mirror the task IDs and link back to the candidate file.

- Preflight script, H0 clarification answers and timed checkpoints:
- Progressive H1/H2/H3 hints with their effect to record:
- Branches for an unfinished core task versus a completed task; keep stretch work optional:
- Expected solution, correctness argument, worked example and limits:
- Complexity/calculations, normal and failing traces, valid alternatives:
- Exact code-validation scope, if any; manually reviewed reasoning must not be labeled executed:
- Common mistakes, strong indicators and six task-specific scoring rows:
- One or two remediations and a new independent variation:
- Primary source support with date and scope, without employer attribution unless actually justified:

## Administration and retrospective

Use the [blank scorecard](../13-Mock-Interviews/Mock_Scorecard.md). Record time, pauses, tools, hints and observable evidence before a score. Keep unobserved dimensions Not assessed. Level 4 needs repeated independent variations; do not derive a hiring decision from a practice total.
