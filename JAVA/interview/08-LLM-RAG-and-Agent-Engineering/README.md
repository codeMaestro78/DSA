The complete [Phase 6 session](../13-Mock-Interviews/AI_Engineer_Mock_Interview.md) and [local transfer variant](AI_Engineering_Mock_Interviews.md) are now delivered. ## Learning sequence

1. Model versus application → tokenization → embeddings → Transformer shapes → context budgets.
2. RAG ingestion/query flow → retrieval strategies → exact/ANN search → hybrid fusion → reranking → evaluation.
3. Bounded agent control → ReAct → tool validation → memory → multi-agent coordination.
4. Framework persistence boundaries and version-pinned MCP, then injection/security/guardrails.
5. Agentic/graph extensions, latency/observability and cost-quality comparisons.
