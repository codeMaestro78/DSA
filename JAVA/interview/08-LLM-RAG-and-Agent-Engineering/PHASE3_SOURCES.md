## Research leads and source-order limits

## Validation boundary

[Local validation](../validation/ai/README.md) uses only authored standard-library functions and dummy values. It does not run a real embedding model, tokenizer, BM25/ANN engine, RAG pipeline, framework, MCP server/client, telemetry backend or hosted LLM. All technology or quality choices still need task-specific integration/evaluation.
