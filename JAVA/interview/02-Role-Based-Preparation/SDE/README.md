## Readiness gate

Specify an input/state contract, derive a correct mechanism, test a boundary and explain a failure under changed assumptions. Use [the shared rubric](../../13-Mock-Interviews/Interview_Evaluation_Rubric.md); one session does not establish repeated transfer or hiring readiness.
