# RAG Engineer preparation

## Delivered preparation scope

This track provides focused role-specific preparation linked to canonical AI/ML and Phase 2 software foundations. All exercises and practice formats are original [INFERRED], company-neutral guidance. Job responsibilities do not establish interview rounds or eligibility.

## How to study

Start with this track's roadmap. Read each canonical mechanism before attempting the role scenario. State the contract, one failure boundary, a justified tradeoff and what evidence would test the claim. Open answer guidance after attempting. Keep real project experience separate from hypothetical exercises.
