# DSA and coding

Phase 2 delivers a core learning sequence, seven teaching/research/index documents, **16 original core pattern guides** and **32 original core practice exercises**. Eight algorithm implementations have focused deterministic/differential validation; this does not mean every exercise has executable tests or all possible coding problems are covered.

Phase 7 fills the six remaining teaching areas, bringing the module to **22 guides and 44 original exercises**. The 12 extension exercises are reviewed traces rather than newly executed implementations; earlier runtime checks retain their stated method scope.
