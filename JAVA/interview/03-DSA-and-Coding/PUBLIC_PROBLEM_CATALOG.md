# Public problem catalog

Phase 5 adds **22 distinct public platform exercises across all 22 DSA areas**. The existing [32 original diagnostic exercises](DSA_Question_Index.md) remain the foundation; they are referenced, not reprinted here. This catalog selects transfer problems rather than claiming company association, interview frequency or leaked prompts. All selection, mechanism and complexity commentary is [INFERRED]. Titles, accessible statements and platform difficulty labels were checked on LeetCode on **2026-11-02** [OFFICIAL]. Difficulty is the platform label, not a mapping to the four editorial bank levels.

Try the linked public statement first. These are original short summaries and solution directions, not copied statements or complete implemented solutions. Bounds assume the platform constraints and unit-cost fixed-width arithmetic; hash bounds are expected under appropriate hashing. Auxiliary space excludes caller inputs and returned output unless explicitly included. n is element count; m/n are source/target lengths for windows; L is total input characters and k maximum word length for anagrams; Σ is alphabet size; h tree height; V/E graph vertices/edges; ℓ query word length, N stored words and S total stored characters for tries. Platform-specific numeric guarantees do not automatically transfer to arbitrary inputs.

## Practice and evidence boundary

For each problem, record the platform ID/title, independent attempt, invariant, failing example, time/space accounting and reattempt date. Reuse the [DSA answer template](../14-Interview-Preparation-Templates/DSA_Problem_Template.md); the catalog itself does not provide platform submissions or claim accepted hidden tests. Begin with arrays, hashing, pointers, search and traversal, then use Hard problems as stretch practice. The concurrency rating is platform difficulty, not a claim that arbitrary concurrency is easy. SQL costs are plan-dependent, so inspect the actual engine plan before making an execution claim.
