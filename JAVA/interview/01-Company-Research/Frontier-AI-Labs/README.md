## How to use the evidence

1. Start with the exact role, level, location and eligibility requirements.
2. Read the official-process and tool-policy section; unknown details stay unknown.
3. Use candidate accounts only with their role/event/report dates and selection limits.
4. Attempt the original company-neutral drill before opening its answer.
5. Ask the recruiter about the remaining decisions and refresh volatile instructions before assessment.

Notable boundaries: Perplexity's agentic format and independent practical/hands-on formats have different tool rules; Mistral's technical-family process differs from GTM/corporate; the inspected x.ai site now uses SpaceXSI branding. Hugging Face's employer ATS body was inaccessible, so official hiring stages were not invented. Some senior role examples do not fit a 0–2 year candidate.
