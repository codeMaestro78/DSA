## How to read status

All original requested topic files and navigation pages are authored. The manifest separates requested paths from supporting source registers, extended DSA guides, interviewer companions and reports. Historical phase reports preserve their original counts and limitations; use the Phase 7 report for final delivery status. File completion does not mean every possible interview topic or external deployment has been exhaustively validated.

Technical practice is normally company-neutral. [OFFICIAL], [CANDIDATE-REPORTED], [COMMUNITY-TREND], [INFERRED] and [UNVERIFIED] labels distinguish evidence from interpretation. Confirm the exact requisition's process and tool policy with the recruiter before an assessment.

## Ongoing use

Choose one primary role, attempt problems before reading answers, and record evidence in the tracker. Recheck the exact employer posting, invitation and tool policy before applying. Unknown employer internals, live provider behavior and blocked runtime checks remain explicit in the QA report; they are not replaced by invented facts.
