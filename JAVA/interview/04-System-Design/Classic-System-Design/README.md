## Evaluate the answer

State requirements and workload assumptions, API/data authority, invariant, normal flow, concrete race/failure, current permissions, recovery and a tradeoff. Workload arithmetic is illustrative and does not prove capacity. The new cases are reviewed designs, not deployed implementations or measured benchmarks.
